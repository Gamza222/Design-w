# Контент и материалы для следующего этапа

Обновлены 18 MDX-страниц: шесть сохранённых slug в RU/EN/BE. Единый шаблон содержит article, один H1, визуальное описание, неповторяющиеся изображения, заявку с кейсом и FAQ. Площадь, адрес, сроки, бюджет и результаты не публикуются без подтверждения. Поля task/solution/area/year/location необязательны и готовы к заполнению.

| Кейс           | Уникальных кадров сейчас, включая обложку | Что нужно                                                                   |
| -------------- | ----------------------------------------: | --------------------------------------------------------------------------- |
| minimal-loft   |                                         2 | Дополнительные ракурсы и подтверждение принадлежности кадров одному проекту |
| warm-scandi    |                                         2 | Уточнение связи двух интерьерных изображений, дополнительные ракурсы        |
| modern-kitchen |                                         2 | Дополнительные зоны и подтверждение состава проекта                         |
| classic-living |                                         1 | Другие ракурсы гостиной и смежных зон                                       |
| cozy-bedroom   |                                         1 | Другие ракурсы спальни и детали                                             |
| studio-loft    |                                         1 | Другие ракурсы и функциональные зоны                                        |

Для каждого кейса нужны: согласованный текст задачи и решения; статус изображения (визуализация или реализованный интерьер); роль студии; разрешение на публикацию; при желании публикации — подтверждённые площадь, город, год, сроки, материалы и бюджет. До получения этих данных страницы описывают только видимое на кадрах. Обложки не дублируются в галерее. `source-assets/` и `finaltask/room1.1.jpg` не использовались.

Публичные отзывы сейчас отсутствуют: подтверждённые записи заказчик не предоставил. Убраны вымышленные имена, тексты, рейтинг 4,9, «500+ проектов» и неподтверждённые счётчики. Модель `VerifiedReview` принимает id, locale, name, text, publishedAt, https sourceUrl, verified=true, publicationConsent=true; city/rating необязательны. Нужны оригиналы отзывов, источник, дата и разрешение автора на публикацию. Интерфейс показывает по 12 записей с кнопкой продолжения; синтетические 150 записей находятся исключительно в unit-тесте. Review/AggregateRating schema не добавлена.

Основной формат URL — завершающий `/`; исторические slug сохранены. Canonical, og:url, sitemap, hreflang и x-default согласованы. У кейсов и статей свои OG-обложки. `llms.txt` содержит действующие ссылки и границы подтверждённых сведений; он не гарантирует попадания в AI-поиск. Для блога сохранены ссылки на оригиналы в Дзене; доступность внешнего Дзена требует отдельной проверки владельцем.

Перед запуском рекламы владелец должен предоставить реальные ID аналитики/кабинетов, перечень целей, доступы и согласованные условия обработки данных. Сейчас передаются UTM и контекст заявки, сторонние трекеры и вымышленные ID не добавлены. Точный блок из нерасшифрованного голосового замечания нельзя достоверно определить — для адресной правки нужен его номер или скриншот.
