# Матрица CTA

| Место                                                                        | Действие                                    | Контекст                                                                |
| ---------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------------------------------------------- |
| Header, мобильное меню                                                       | Открыть короткую форму                      | header; возврат фокуса на мобильный burger                              |
| Hero                                                                         | Открыть короткую форму                      | hero                                                                    |
| Вводная карточка пакетов                                                     | Открыть короткую форму                      | package-intro                                                           |
| Карточка пакета                                                              | Открыть короткую форму                      | package-card, пакет, название, валюта                                   |
| Карточка в ленте услуг                                                       | Открыть подробности услуги                  | Выбранная услуга; это просмотр информации                               |
| «Обсудить эту услугу» в подробностях                                         | Закрыть подробности, открыть короткую форму | service-details, выбранная услуга/пакет, валюта                         |
| Каталог /services/                                                           | Открыть короткую форму                      | services-list, услуга/пакет, валюта                                     |
| Посадочные трёх услуг                                                        | Открыть короткую форму                      | service-page, выбранная услуга/пакет, валюта                            |
| Калькулятор                                                                  | Открыть короткую форму                      | calculator, площадь, пакет, допуслуги, сумма, валюта, предварительность |
| Опасения и география                                                         | Открыть короткую форму                      | fears / geography                                                       |
| Страница кейса                                                               | Открыть короткую форму                      | project-page, slug кейса                                                |
| Consultation на главной                                                      | Отправить уже видимую форму                 | services-consultation                                                   |
| ContactCta на главной, услугах, контактах, портфолио, о студии, блоге/статье | Отправить уже видимую форму                 | contact-form, площадь, выбранная услуга                                 |
| Footer: телефон, email, VK, карта                                            | Соответствующий контактный канал            | Обычные ссылки                                                          |
| Header/footer «Контакты», «Портфолио», «Подробнее»                           | Навигация                                   | Не являются кнопками заявки                                             |

Для открытия заявки нет перехода на другую страницу или принудительного скролла. Форма из калькулятора не спрашивает повторно его параметры. В обеих формах: consent, серверная валидация, блокировка повторной отправки, стабильный submissionId при повторе, новый ID после редактирования, номер успешной заявки. У модальной формы есть Escape, фокус, цикл Tab и блокировка фоновой прокрутки. UTM хранится в памяти вкладки, сохраняется при SPA-навигации и отправляется вместе с согласованной заявкой.

Неиспользуемые старые OrderModal и CalcCard не участвуют в действующем интерфейсе.
