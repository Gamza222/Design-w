## Контекст

Имиджевый лендинг студии дизайна интерьера: тёмная фирменная стилистика (navy `#081125`) + золотой
акцент (`#febc04`), премиум-ощущение «дорогой студии». Сейчас собрано ~4 из 12 секций воронки (Hero +
Packages + Services + Portfolio + Blog + кнопка-CTA). ТЗ описывает полную воронку и несколько типов
внутренних страниц.

**Цель:** довести сайт строго до ТЗ — полностью адаптивный (флюид rem+clamp), производительный, где
заказчик меняет **тексты в i18n-JSON, статьи/проекты в MDX, картинки в `/public/images`** — и сайт
обновляется. Hero и навбар: **контент как есть, дизайн улучшаем**. Формы пока без бэкенда (валидируем,
отправка — заглушка). SEO-страницы услуг — делаем. Навбар — 5 текущих пунктов, только полировка.

## Дизайн-фундамент (Фаза 0)

- **Тональность секций.** Сайт чередует тёмные/светлые блоки. Вводим `Section tone="dark"|"light"|"glass"`,
  который **переопределяет семантические токены** (`--color-bg/-surface/-text/-text-muted/-border`).
  Компоненты — theme-agnostic, через семантические токены, без хардкода. Сырьё (`--clr-*`) не трогаем.
- **Новые токены:** тёмные поверхности/бордеры, glass (blur+прозрачность+золотая линия), `--glow-accent`, ритм секций.
- **Новые shared-примитивы** (`src/shared/ui/`): `SectionHeader`, `Input`/`Textarea`/`Field`, `PillToggle`,
  `Checkbox`, `Accordion`, `Badge`/`Tag`, `Stat`, `IconBadge`, `Breadcrumbs`, `Stepper`, `Rating`, `GlassPanel`.
  `Button` — размеры; `Section` — проп `tone`; расширить `Icons.tsx`.
- **Анимация:** общий `useReveal()`/`<Reveal>` в `src/shared/lib` (fade-up по скроллу, safe к `prefers-reduced-motion`).
  Паттерн GSAP/ScrollTrigger уже отлажен (Hero/Packages) — следовать ему; ScrollSmoother-синглтон не ломать.

`npm run typecheck && npm run lint && npm run lint:fsd && npm test && npm run build && npm run e2e`.
